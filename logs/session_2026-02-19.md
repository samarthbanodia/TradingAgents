## Part 1: Spec Gap Fixes (4 files)

### `agents/prompts.py`

**SKEPTIC_SYSTEM — question keys and value types**
- Changed `"micro"` key → `"microstructure"` in `questions_for_each_agent`
- Changed values from single strings to arrays `[≤2 strings]` per spec
- Old: `"micro": <string>`
- New: `"microstructure": [<string>, <string>]`

**JUDGE_SYSTEM — dominance rules rewritten**
- Old thresholds: `score >= 0.6 AND diff >= 0.2` (3 classes)
- New thresholds: `diff > 0.10` (4 classes, applied in order)
- Old class name: `"information"` → New: `"info"`
- Added 4th class: `"noise"` (both signals weak, max < 0.40)
- Full new rules:
  - `final_I > final_P + 0.10` → `"info"` → `"continuation"`
  - `final_P > final_I + 0.10` → `"panic"` → `"reversal"`
  - `|I-P| <= 0.10 AND max(I,P) >= 0.40` → `"mixed"` → `"unclear"`
  - else → `"noise"` → `"unclear"`

**`format_revision_input()` — list handling**
- Changed lookup key from `"micro"` → uses `agent_key` parameter (caller passes `"microstructure"`)
- Added list join: if question value is a list, joins with space before injecting into prompt

- `validate_skeptic_output(raw)` — validates critique_points[:4], questions_for_each_agent (microstructure/news/macro keys, list values[:2]), suggested_adjustments (I_delta/P_delta clamped to [-0.3,+0.3]), confidence_delta clamped to [-0.4,+0.2]
- `validate_judge_output(raw)` — clamps final_I/P/confidence; if dominant_class not in {info,panic,mixed,noise} OR policy_behavior not in {continuation,reversal,unclear}, falls back to code-computed values from derive_dominant_class()
